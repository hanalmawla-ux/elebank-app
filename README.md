# EleBank - تطبيق أندرويد / آيفون

## أندرويد (بدون تثبيت أي برنامج على جهازك)
1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository).
2. ارفع كل محتويات هذا المجلد إلى المستودع، مع المجلد المخفي `.github`.
   إذا لم يرفعه السحب والإفلات: Add file > Create new file واكتب المسار `.github/workflows/android.yml` والصق محتوى الملف.
3. افتح تبويب Actions. يبدأ البناء تلقائياً (أو اضغط Run workflow). يستغرق بضع دقائق.
4. من صفحة التشغيل الناجح نزّل الملف EleBank-apk وفك ضغطه، ستجد app-debug.apk.
5. انقله إلى الجوال وافتحه. فعّل "التثبيت من مصادر غير معروفة" إذا طُلب.

## آيفون (يحتاج جهاز Mac وبرنامج Xcode)
npm install && npx cap add ios && npx cap sync ios && npx cap open ios
للتثبيت على جهازك أو النشر في App Store تحتاج حساب Apple Developer (99 دولاراً سنوياً).

## تغيير أيقونة التطبيق مع لون الثيم
- عند اختيار لون من الإعدادات، تتبدّل أيقونة التطبيق على الشاشة الرئيسية إلى أيقونة بنفس اللون.
- أندرويد: يتم تلقائياً في البناء على GitHub (الخطوة patch-android.js). قد يتأخر المشغّل (launcher) بعض الثواني في عرض الأيقونة الجديدة، وبعض الأجهزة تُغلق التطبيق لحظة التبديل.
- آيفون: بعد `npx cap add ios` شغّل `node scripts/patch-ios.js` ثم افتح المشروع في Xcode. يظهر تنبيه من النظام عند كل تبديل، وهذا من آبل ولا يمكن إخفاؤه. السكربت غير مجرَّب.
- تبديل الأيقونة يعمل في التطبيق الأصلي فقط، وليس في نسخة المتصفح.

## ملاحظات
- ملف APK هذا للتجربة (debug). النشر في Google Play يحتاج نسخة موقّعة.
- تعديل التطبيق: عدّل www/index.html ثم أعد البناء.
